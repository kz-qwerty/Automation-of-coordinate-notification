# Automation-of-coordinate-notification
Telegram-бот для водителей. Он следит за геопозицией водителя и сам сообщает в группу, что водитель выехал, доехал до адреса и едет на следующий адрес.  Пользователям больше не нужно звонить и спрашивать: «Где водитель?». Водителю не нужно больше отвлекаться на телефон чтобы каждый адрес подтверждать.
